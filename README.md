# 数字人动作跟随

浏览器里的 3D 数字人，通过摄像头实时捕捉你的动作并镜像跟随（身体、头部、表情、手指）。

## 运行

```bash
./scripts/fetch-assets.sh      # 仅首次：下载库和模型到 vendor/、models/（约 72 MB，需要 ffmpeg 转换贴图）
python3 -m http.server 8765
# 打开 http://localhost:8765 ，点击「开启摄像头」
```

资源下载完后完全离线可用，运行时不访问任何外部网络。摄像头需要安全上下文：`localhost` 或 HTTPS。无需构建。

## 技术栈

| 环节 | 方案 |
| --- | --- |
| 人体/手/脸关键点 | MediaPipe Tasks Vision：PoseLandmarker、HandLandmarker、FaceLandmarker（含 blendshapes），GPU 推理 |
| 关键点 → 骨骼旋转 | `solver.js` 直接 3D 重定向（躯干、四肢、头、手腕、全部手指含拇指）；Kalidokit 只用于整体位移 |
| 渲染 | three.js + @pixiv/three-vrm（VRM 0.x / 1.0 都支持），写实模型用 PBR 材质 + 环境光照 |
| 写实数字人 | [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox)（MIT，可商用），带 ARKit 52 表情 |

## 说明

- 左侧下拉框切换数字人：默认是 Rocketbox 写实模型，也保留了二次元 VRM 示例；还可以上传或拖入自己的 `.vrm`。
- 写实模型的面部由 MediaPipe 输出的 52 个 ARKit blendshape 直接驱动（眨眼、挑眉、眼球、嘴型、鼓腮等）。
- 想换其他 Rocketbox 人物（共 115 个）：在 `scripts/fetch-assets.sh` 的 `ROCKETBOX` 列表里加一行 `"目录:贴图前缀"`，再在 `main.js` 的 `AVATARS` 里加一项。
- 适配逻辑在 `avatars.js`：Rocketbox 用的是 3ds Max Biped 骨骼、A-pose，加载时会调整骨骼父子关系、摆成 T-pose，再映射到 three-vrm 的人形骨骼，所以和 VRM 共用同一套驱动代码。
- 镜像跟随：你抬左手，数字人抬右手，就像照镜子。
- 下半身不在画面里时腿部自动保持站姿；不需要时可关掉「腿部」「身体位移」。
- VRM 1.0 模型朝 +Z，VRM 0.x 朝 -Z，`main.js` 里用 `axisSign` 统一了 Kalidokit 的旋转方向。

## 捏人

点"捏人"打开编辑器（镜头会推到脸部），分四页：

| 页 | 内容 | 支持的模型 |
|---|---|---|
| 脸部 | 17 项：头部大小、颧骨、下颌、下巴长短/前后、眼睛大小/眼距/高低/深浅、眉毛高低/眉尾/眉骨、鼻子大小/高低/鼻梁、嘴宽/唇厚/嘴高 | 写实 |
| 身体 | 身高、肩宽、脖子、躯干、手臂、腿长、手掌、脚 | 写实 + VRM |
| 颜色 | 肤色（6 档）、发色（9 种）、瞳色（8 种）、服装色相/饱和度 | 写实 |
| 存档 | 导出/导入形象文件（JSON） | 全部 |

- 每页可"随机"或"重置本页"，双击滑块单独归零；形象按数字人分别自动保存在浏览器本地。
- 脸部：移动/缩放 Rocketbox 自带的 30 根面部骨骼（`sculpt.js`）。面部骨骼不参与跟随，表情走变形，所以捏完照常跟随。
- 身体：改原始骨骼的骨长和缩放；跟随只写旋转，所以两者互不干扰，贴地也会自动适配。
- 颜色（`colors.js`）：Rocketbox 的皮肤、头发、衣服画在同一张贴图上，没有遮罩。加载时按颜色分类，再经去杂点、闭运算、区域生长生成遮罩贴图（皮肤 / 头发）；虹膜按眼球贴图中心的圆定位；着色器里按原贴图明暗换色，保留纹理细节。

## 场景与输出

左侧"场景与输出"：

- 背景：深色、浅色、渐变、绿幕、蓝幕（绿幕/蓝幕去掉地面和阴影，方便直播抠像）
- 灯光：摄影棚、柔光、暖光、冷光、戏剧
- 截图（PNG）、录制视频（WebM，录的是 3D 画面，不含界面）
- 按 H 隐藏/显示全部界面

## 跟踪流程

1. 姿态模型在整幅画面（1280×720）上找身体关键点，经 One Euro 滤波去抖。默认用 heavy 模型（更准），界面上可切换为 full（更快）。
2. 根据身体关键点定位脸和两只手，各裁一块正方形放大到 256×256，再交给面部/手部模型。人站在 2 米外时脸和手只有几十像素，不裁剪的话根本检测不到。预览窗口里橙框是脸、绿框是手，底部状态栏显示哪些部位跟丢了（✕）。
3. 身体直接 3D 重定向：每段骨骼对准 MediaPipe 测到的 3D 方向；上臂/大腿额外对齐肘/膝的弯曲平面，避免关节拧麻花；躯干由肩线和髋线定朝向；头部由面部网格（眼角连线、额头-下巴）定朝向，脸跟丢时退回用姿态的耳朵和五官。
   手腕用手掌朝向（手指方向 + 掌心法线）确定，翻掌的扭转一半分给小臂，避免腕部蒙皮拧麻花；每个指节（含拇指）同样直接对准手部 3D 关键点，弯曲和张开都会还原。
4. 所有骨骼只设定目标值，每个渲染帧按时间插值过去，所以 30fps 的摄像头在 60fps 画面上也连续。
5. 检测闪断时短暂保持最后的姿势（手 0.4 秒、身体 0.5 秒），超过才回落。
6. 髋部或腿不在画面里时（坐在桌前），或躯干在画面里明显不是竖直的（多为误识别），对应部位回到默认姿势，不使用模型的猜测。
